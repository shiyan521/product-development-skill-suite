# Product Development Skill Suite · 产品开发全链路 Skill 套件

> **从 Idea 到变现，13 个 AI Skill 覆盖产品开发全链路。**
>
> 每一个 Skill 都来自真实产品开发的实战经验，不是纸上谈兵。

---

## 故事

2026 年，我用 AI Agent 做了几个产品。

从博士求职工具到公众号矩阵，从知识图谱到内容营销。每一个项目都踩过坑，每一个坑都沉淀成了经验。

做着做着发现一个规律：**产品开发这件事，本质上是一套可重复的流程。**

市场调研 → 竞品分析 → 需求挖掘 → 写 PRD → 设计架构 → 评估数据源 → 写代码 → 复盘 → 记录流程 → 定价 → 内容营销 → 分析竞品内容 → 优化自己的表达

13 个环节，13 个 Skill。

我把它们打包成了一套"产品开发全链路 Skill 套件"。不是理论，是每个 Skill 都经过真实项目验证的工具。

## 13 个 Skills 速览

### Phase 1：市场验证（Market Validation）

| # | Skill | 做什么 | 触发词 |
|---|-------|--------|--------|
| 01 | **market-researcher** | 行业扫描、市场规模估算、用户痛点验证 | "市场调研"、"行业分析" |
| 02 | **competition-analyzer** | 竞品多维拆解、差异化定位、壁垒评估 | "竞品分析"、"竞争格局" |
| 03 | **user-need-miner** | 从用户访谈/社交媒体中提取真实需求 | "用户需求"、"用户画像" |

### Phase 2：产品定义（Product Definition）

| # | Skill | 做什么 | 触发词 |
|---|-------|--------|--------|
| 04 | **prd-writer** | 结构化 PRD 生成，含功能定义、技术方案、路线图 | "写PRD"、"产品需求文档" |
| 05 | **tech-architect** | 技术选型、架构设计、数据模型、部署方案 | "技术架构"、"技术方案" |
| 06 | **data-source-evaluator** | 数据源评估、采集策略、数据壁垒分析 | "数据源"、"数据采集" |

### Phase 3：开发测试（Development & Testing）

| # | Skill | 做什么 | 触发词 |
|---|-------|--------|--------|
| 07 | **code-reviewer** | 代码质量审查、Bug检测、安全漏洞扫描 | "代码审查"、"Code Review" |
| 08 | **project-retrospective** | 项目复盘、时间线重建、经验提取 | "项目复盘"、"经验沉淀" |
| 09 | **process-keeper** | 工作流记录、决策追踪、流程打包 | "记录流程"、"决策记录" |

### Phase 4：商业化（Commercialization）

| # | Skill | 做什么 | 触发词 |
|---|-------|--------|--------|
| 10 | **pricing-strategist** | 定价策略、用户付费意愿分析、变现路径 | "定价"、"商业化" |
| 11 | **content-marketer** | 内容矩阵设计、选题规划、分发策略 | "内容营销"、"选题规划" |

### Phase 5：内容营销（Content Marketing）

| # | Skill | 做什么 | 触发词 |
|---|-------|--------|--------|
| 12 | **video-content-analyzer** | 爆款结构拆解、钩子/骨架/收口分析、公式提炼 | "爆款拆解"、"内容结构分析" |
| 13 | **speech-analyzer** | 20维度口头表达分析、表达质量量化 | "直播分析"、"口才评估" |

## 安装使用

### 方式一：作为 Trae Skill 安装

```bash
# 克隆到本地 Skills 目录
git clone https://github.com/shiyan521/product-development-skill-suite.git
cp -r product-development-skill-suite/skills/* <your-trae-skills-dir>/
```

### 方式二：单独使用

每个 Skill 都是独立的，可以直接复制 `skills/<skill-name>/SKILL.md` 到你的 Trae Skills 目录使用。

### 方式三：按需选取

不需要全部安装。根据你当前的项目阶段，选对应的 Phase 即可：

- 刚有 Idea → 装 Phase 1（市场调研 + 竞品分析 + 需求挖掘）
- 准备开发 → 装 Phase 2（PRD + 技术架构 + 数据源）
- 开发中 → 装 Phase 3（代码审查 + 复盘 + 流程记录）
- 准备上线 → 装 Phase 4（定价 + 内容营销）
- 开始运营 → 装 Phase 5（视频分析 + 表达分析）
