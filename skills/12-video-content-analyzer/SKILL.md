# 视频内容拆解器

> 产品开发全链路 Skill #12 · 从爆款视频里挖出「能复制的动作」

拿到逐字稿之后，回答一个问题：**这条为什么火，能复制什么。**

---

## 定位：分析层

本 skill 只做**解读**，不做采集。逐字稿从上游来：

| 环节 | 用什么 |
|---|---|
| 采集 + 转录（账号 / 关键词 → 逐字稿） | 逐字稿采集工具（见文末参考） |
| **内容拆解 + 爆款公式** | **本 skill** |

**前置**：手上要有一份逐字稿（合集或单条）。没有就先采集。

---

## 什么时候用它

**用：**
- "拆一下这条为什么火"
- "这个号的内容结构是什么套路"
- "提炼一下它的爆款公式"
- "对标账号拆解"

**不用：**
- 要视频数据 / 逐字稿 → 先做采集
- 已有逐字稿、要写新稿 → 用脚本写作类 Skill
- 给素材打分 → 用素材评分类 Skill

---

## 四步拆解

| 步 | 拆什么 | 看什么 |
|---|---|---|
| ① 钩子 | 开头 3 秒怎么留人 | 数字型 / 悬念型 / 痛点型 / 反差型 |
| ② 骨架 | 中段怎么铺 | 总-分-总 / 故事型 / 清单型 / 螺旋型 |
| ③ 收口 | 结尾怎么转化 | 引导关注 / 引导评论 / 引导私信 / 无转化 |
| ④ 公式 | 可复用什么 | 高频选题、固定句式、情绪节奏 |

**拆解要落到「能抄的动作」**，不要停在"讲得好"这种空判断。

---

## 输出格式

`{账号}-内容拆解.md`，结构：

```text
## 一、账号概览
（定位 / 更新节奏 / 高赞集中区）

## 二、逐条拆解
| 标题 | 赞 | 钩子 | 骨架 | 收口 | 可复用点 |

## 三、爆款公式
（高频结构 + 固定句式 + 选题方向）

## 四、对我们的启示
（能直接用的 3~5 条）
```

## 硬约束

1. 逐字稿仅用于**内部分析与学习**，不二次分发、不商用转载
2. 拆解结论要落到**可执行动作**，禁止"内容优质""表达流畅"这类空话
3. 引用他人观点 / 数据时标注来源
4. 只用公开可获取的内容，不绕风控、不碰黑产
